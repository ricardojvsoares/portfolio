# Portfolio

Personal portfolio built with Next.js.

## Stack

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4 + shadcn
- next-intl (pt-PT / en-EN)

## Setup

```bash
pnpm install
pnpm dev
```

## Scripts

| Script                      | Purpose    |
| --------------------------- | ---------- |
| `pnpm dev`                  | Local dev  |
| `pnpm build` / `pnpm start` | Production |
| `pnpm lint`                 | ESLint     |

## Deploy

Deploy as a standard Next.js app (e.g. Vercel). No database or env vars required.
